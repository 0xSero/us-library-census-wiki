# US Library Census Wiki

A Wikipedia-style browsable interface for the US Library Census — a living dataset of every public and private library, and every government website, in the United States.

## Stats
- 46,410 total nodes
- 17,615 public libraries
- 3,770 private/academic libraries
- 25,025 government websites
- 37,865 geocoded map points

## Features
- Interactive MapLibre GL JS map with 37k+ WebGL-rendered points
- Full-text search across all records
- Per-state pages (56 states/territories)
- Government site verification by tier
- Library hours and services data

## Data Sources
- IMLS Public Libraries Survey FY2024
- NCES IPEDS Academic Libraries 2023
- CISA dotgov-data + GSA govt-urls
- Census ACS 2023 5-Year demographics
- Google Places API + Gemini LLM ratings
